ルール:
1. 【本日の業務】: 各カレンダーイベントを1行ずつ、時間なし、形式: `・カテゴリ：内容`（まとめない）
   - **重複禁止**: カテゴリと内容が同じになる場合（詳細なし）は `・Zendesk対応` のようにカテゴリのみ（コロン以降なし）
     NG例: `・Zendesk対応：Zendesk対応`　→　OK例: `・Zendesk対応`
   - **面談の種別表記ルール（カレンダータイトルに基づく）**:
     - タイトルに「訪問」あり → `訪問定期面談：[法人名 氏名]`
     - タイトルに「対面」あり → `対面定期面談：[法人名 氏名]`
     - 上記どちらもなし（デフォルト） → `オンライン定期面談：[法人名 氏名]`
     - 日々面談 → `日々面談：[氏名]さん`
   - **具体例**:
     ```
     ・訪問定期面談：社会福祉法人明桜会 MUHAMMAD WIDHI FADHIILAH
     ・対面定期面談：〇〇会社 氏名
     ・オンライン定期面談：社会福祉法人清水福祉会 QIN XIAOBEI
     ・日々面談：Anisa Pebriani Zulkarnaenさん
     ・Zendesk対応：アパートの設備について
     ・Zendesk対応  ← 詳細なしの場合はこれだけ
     ・その他：電話 Leopalaceへ設備故障について
     ```
2. 【共有・相談】: デフォルト「なし」
3. 【明日以降の業務】: ユーザーが手動入力（デフォルト「・」）
4. 【今週実行するDNA】: **固定値「・自己管理する」**（変更指示があるまでこの値を使い続ける）
5. 【今日私が素晴らしいと感じたDNA】: 箇条書き記号「・」なし、以下の2行形式:
   ```
   (名前)さん：(DNA名)
   (日本語説明文)
   ```
   例:
   ```
   Inaさん：仲間である
   ヤマト福祉会の支援者の引っ越しフローについて相談を受けてくださり、ありがとうございます。物件探しを手伝う前に、企業と支援者の状況をしっかり確認します。
   ```
6. 【KPI進捗（実績 / 月次目標）】:
   - 定期面談進捗：小数点第1位まで（例: 80.4％）/ 100％
   - TQL数：ユーザー指定値 / 3
   - 日々面談：件数のみ（「件」は不要）/ 40
7. 【本日のTQL詳細】: **削除**（入れない）
8. 署名ブロック: 必ずKPI進捗の後に追加（ーーーで囲む）

**Why:** ユーザーが正しいフォーマットを提示。旧フォーマットより多くのセクションを含む。
**How to apply:** 「laporan harian」実行時のメールドラフト出力で、このフォーマット全体を使う。
