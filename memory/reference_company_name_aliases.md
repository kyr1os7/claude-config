面談予約（Google Calendar のイベント説明「会社名」欄）に支援者本人が書く名称は、正式名称ではなく略称・ローマ字表記のことがある。業務報告（メール・Kintone App 241）では**正式な会社名**に直すこと。

## マッピング
- `Jisekai` / `Jiseikai` → **医療法人社団慈誠会**（2026-07-21 ユーザー指摘）

**Why:** 予約フォームは支援者が自由記入するため表記ゆれがある。業務報告は正式名称で統一。
**How to apply:** 「laporan harian」でカレンダーの会社名を使う前に、このマップにあれば正式名称へ変換。新しい対応が判明したら追記。関連: [[daily-interview-label-difference-between-kintone-and-email]]
