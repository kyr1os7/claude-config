Jangan mengusulkan atau menyiapkan perubahan pada workflow automation yang sudah berjalan kecuali user memintanya. Kalau user bertanya "gk bisa disamakan?" atau ragu terhadap usulan perubahan, default = **pertahankan cara lama**.

**Why:** 2026-10-11 saya terus menyiapkan intake Zendesk API untuk `zairyucard` & `shoruikakunou`, padahal user ingin tetap seperti sekarang (download manual ke folder Downloads). User kesal: "udah nurut aja napa".

**How to apply:** Saat migrasi/merapikan sistem, pindahkan apa adanya. Kalau ada risiko nyata, sebut sekali secara singkat, lalu ikuti keputusan user tanpa mengulang.
