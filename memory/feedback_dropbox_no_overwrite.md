NEVER delete or overwrite existing files in cloud storage (Google Drive or Dropbox). If a duplicate file exists, leave it as-is and keep both files.

**Why:** User explicitly instructed this - existing files must be preserved at all costs.

**How to apply:** When uploading/moving files to Google Drive or Dropbox, always add new files. Never use overwrite/replace options. If same filename exists, let it be duplicated.
